ブロークングリッドレイアウトとは

通常のグリッドの整列を意図的に崩し、要素をグリッドの境界をまたいで重ねることで動的・デザイン性の高いレイアウトを実現する手法。

  • CSS Grid の grid-column / grid-row でセルをまたがせる
  • z-index で重なり順を制御する
  • transform: translate() や負のマージンでグリッド外にはみ出させる

サンプル1: 画像×テキストのオーバーラップ

4列×3行のグリッドで、画像ブロック（col1〜2 / row1〜2）とテキストブロック（col2〜4 / row2〜3）が col2・row2 のセルで重なる。z-index でテキストを前面に。

サンプル2: position: absolute による配置

親要素に position: relative を指定し、子要素を position: absolute で top / left / right / bottom で自由配置する。 グリッドなしでも重なりや「ずれ」を表現できる。
